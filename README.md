# MAZE

## Installatie
Clone het:
```powershell
git clone https://github.com/egol1/MAZE.git
```

Installeer alle packages:
```powershell
npm install
```

Run het:
```powershell
npm run start
```

Dat is het.
Als de pagina niet automatisch laadt, vind je het bij [localhost:3000](http://localhost:3000).
